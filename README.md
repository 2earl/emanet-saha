# Emanet Saha

Emanet for field agents at **emanet-saha.2earl.com**: find vehicles that carry a seizure order,
report them to the police, and follow each one to a custodian car park. Web and mobile.

Built on [Emanet core](https://github.com/2earl/emanet-core); sign-in with login.2earl.com.

Emanet is a private service, not a public authority. Agents never touch, tow or block a vehicle.
